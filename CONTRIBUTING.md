# Contributing

Thank you for your interest in the Omada Identity MCP Server.

## Reference Project — No Pull Requests

This project is a reference implementation from Omada's innovation initiative.
To keep IP ownership clean for future commercialization,
**we are not accepting pull requests at this time**. PRs will be closed without review.

## How to Give Feedback

For bug reports, questions, or feature suggestions, please reach out through our
**[support channel on Freshdesk](https://omadasupport.freshservice.com/a/tickets/new)**.

When reporting a bug, include:
- Your Python version and OS
- MCP client in use (e.g. Claude Desktop, GitHub Copilot)
- The exact error message or unexpected behavior
- Do **not** include credentials, tokens, or internal hostnames

## Security Issues

Do **not** use Freshdesk for vulnerability reports — see [SECURITY.md](SECURITY.md) instead.

## Future Contributions

We plan to open contributions in a future release. Watch this repo for updates.
